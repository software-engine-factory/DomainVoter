# Persian copy glossary (DomainVoter)

All user-facing strings live in `src/lib/copy/fa.ts` (`import { t } from "@/lib/copy/fa"`).
Tone: friendly and a little casual. Voter-facing and admin-facing copy uses the informal singular
("رأی بده", "وارد شو"); keep it consistent.

| Concept | Use | Avoid |
|---|---|---|
| round | دور (new: دور تازه) | دور جدید |
| vote / votes | رأی / رأی‌ها | آرا |
| voter(s) | رأی‌دهنده / رأی‌دهنده‌ها | رأی‌دهندگان |
| admin | مدیر | — |
| viewed / seen | دیده‌شده؛ viewers = بیننده‌ها | باز شده، بازدیدکنندگان، پوشش |
| bookmark / pick (admin) | نشان کردن / نشان‌شده‌ها | منتخب، برگزیده |
| for-sale pool | نام‌های فروشی | استخر، استخر فروشی |
| evidence | نشانهٔ فروش | شاهد |
| sale page | صفحهٔ فروش | — |
| nameserver | نیم‌سرور (NS) | — |
| NS class | نوع NS | کلاس NS |
| parking provider | سرویس پارک | پارکینگ |
| marketplace | مارکت‌پلیس | بازار |
| import / sync | وارد کردن / به‌روزرسانی | درون‌ریزی، همگام‌سازی، درج |
