# Remaining performance risks in the current application

Revision: `0506c5e`. This is a static audit unless a row links to a measured experiment. It identifies implementation scope, not additional reproduced incidents.

| `src/lib/batches.ts:133` | `openBatchRound` inserts a whole round in one synchronous transaction on the web connection. | Reproduced with an allowed single 800,000-name round. Worker option A must cover round materialization, not just batch selection. |

## Decisions held for implementation

The experiments do not migrate production schemas, replace SQLite, or change existing voting and set rules. A durable job schema, queue limits and publication semantics are proposed architecture for owner selection. Keeping only the first round ready is an explicit optional choice; it cannot silently replace an administrator's request to create all rounds.
